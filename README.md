# Phigros 离线共存测试项目

基于 Phigros 4.0.1（157）的非官方 arm64 本地测试修改版。当前发布 **164 预发布测试版**。

## 下载

[进入 Releases 下载](../../releases)。下载同一版本的全部 `Phigros-offline-164.7z.00*` 分卷及 `SHA256SUMS.txt`。全部放在同一文件夹，用最新版 7-Zip 打开 `.7z.001` 解压得到 APK。分卷本身不是 APK，不能直接安装。分卷和解压后 APK 均可按校验文件验证。仓库 Git 历史不存放大型 APK。

修改版包名：`com.PigeonGames.Phigros.offline`。正版：`com.PigeonGames.Phigros`。两者签名不同、应用数据目录独立。请先自行备份正版 APK 和自己的存档，不将修改版存档覆盖到正版。卸载修改版会删除其内部数据。运行不依赖 root、LSPosed 或 Frida。

## 功能与限制

- 已核对内容的本地解锁、收藏与常规历史 AP。少数货币解锁歌曲仍走游戏原有流程，不承诺每个内容页均覆盖。
- 每次冷启动询问自动游玩，默认关闭。开启后本次会话产生的游戏成绩计划在下次冷启动恢复；完整真机保存回归待完成。普通关闭启动不加载原生修改库；启用后在同进程关闭开关不会卸载已经加载的库。
- 164 新增可拖动半透明浮窗、音量键快捷操作、目标分数、Miss / Good / Bad，以及编号、范围、列表、随机数量、连续数量选择。首次启动按提示授予悬浮窗权限。
- 音量上键作为菜单快捷键，音量下键关闭；菜单打开时拦截音量键，菜单关闭时下键恢复调音量，上键仍作为菜单入口。
- 指定音符判定优先于目标分数；目标分数仅覆盖结算数值，判定分布不会自动变成对应的自然成绩。位置从全谱时间排序后的第 1 个音符起计数，越界项忽略，随机数量限制到谱面长度。
- 目标历史 RKS 支持最多四位小数，保存后在下一次**进程冷启动**修改本地历史，不是持续固定 RKS。普通后续游玩仍会改变它。范围由实际谱面定数与公式决定，不保证任意目标可达。
- 全 AP 历史默认计算约 17.3167。独立算法示例目标 16.00 后仍有 139 个 AP，其余历史为合成非 AP；这不是游戏内实测记录。收藏与剧情字段保留。
- RKS 修改前在修改版自己的 `files/offline-rks/backups/<时间>/` 备份两个存档 XML；菜单的恢复备份操作在下次冷启动恢复。不要把这个备份恢复到正版包。
- 不含 INTERNET 权限；不要把模拟成绩上传或用于排行榜、云同步或真实成绩证明。

## 启动修复

提取索引漏掉原版主包中的 `sharedassets0.resource` 导致音效加载空指针；补齐后还发现 `unity default resources` 缺失导致章节皮肤加载失败。最终补齐主包全部 11 个 Unity 数据文件，保留原始游戏 native 与资源 CRC。单纯把资源移到 APK 2GB 偏移以内不是确认的根因。

## 源码范围

`src/` 为本项目的 Java 浮窗、会话与 RKS 处理、native 控制源码；`data/` 为与内容版本匹配的谱面目录。此仓库保留可审核的修改源，**不是从零可独立构建整个游戏的工程**。需要合法获得的原版资源、移交工程及自己的签名设置；未附签名私钥、密码、私人存档、手机日志、设备身份或登录凭据。版本相关地址需实证适配，不可套用到其他版本。
