# Phigros 离线共存测试项目

**当前预发行候选：177。** 176及更早版本继续作为历史记录。**177尚未完成本轮真机验收**：电脑端编译、签名、资源检查、JNI 和主机测试不能替代手机启动与整局游玩。

**用途：仅限本地。此修改版不能登录账号，不提供排行榜、云存档或其他线上操作，不声明网络权限。两个 LSPosed 模块保留宿主联网的策略不适用于这个 APK。**

## 177 的主要变化

- 判定规则支持随机K个音符，并继续支持按键种类、指定编号、范围、列表、连续K和全部音符。
- 自动游玩可切换是否屏蔽真实触摸；关闭屏蔽时真实触摸优先，宿主未消费时才补自动输入。
- 成绩保护支持 S、FC、AT，并可额外指定最低保护分数；显式规则优先，离目标越远越倾向救成Perfect。
- 全AP种子改为可重复增量合并，修复一次性标记阻止后续目录新增曲目补记录的问题。
- 免责声明继续在启动和使用面板中显示，按钮采用固定浅色布局。

Phigros 4.0.1.2尚未适配：工作区没有该版本官方APK和对应ELF，不能只改版本号冒充适配。

## 下载与安装

从177预发行页下载全部标准ZIP分卷：

- `Phigros-offline-v177.z01`
- `Phigros-offline-v177.z02`
- `Phigros-offline-v177.zip`

保持文件名、放在同一文件夹，**打开最后的 `.zip` 解压**，没有密码。解出一个 APK，分卷本身不能安装。另附 `SHA256SUMS.txt`，下载或解压异常时先核对各卷哈希。换格式不代表手机端间歇下载损坏的原因已被修复。

包名 `com.PigeonGames.Phigros.offline`，基于4.0.1（157）arm64。独立数据目录，签名与173一致；备份修改版数据后覆盖安装，不卸载、不清除原版或修改版数据。运行不需要 root 或 LSPosed。不声明网络权限，不用于在线排行榜或真实成绩证明。

## 既有功能与边界

- 修复自制谱首次 JNI 字符串转换和路径错误分类，增加应用内导出、删除。
- 调整 Bad 提前触发和未击中清理路径，实际画面与音效待设备确认。
- 自制章节皮肤保留特效、音效和 Perfect/Good 颜色，缺失时才用默认资源。旧导入丢失的文件需要从原包重新导入。
- 改用标准 ZIP 分卷；ZIP4J、7-Zip、SevenZipJBinding 均已完整解压并核对 APK 哈希。

**Phigros 原生章节的扩展特效、音效与判定线颜色尚未完成。** 自制谱、自动游玩触摸开关和成绩保护仍需真机整局验收。详细记录见 [177验证文件](docs/VERIFICATION-177.json)。

对应修改源码位于 `chapter-player/` 及其 `android-source/`；完整自制谱播放器对应源码随发行附件提供。根目录 `src/` 是历史快照。仓库不是从零构建整个游戏的工程。
