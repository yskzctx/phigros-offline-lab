# 173 正式发行版：下载、安装与验证范围

发布日期：2026-10-17。基于 Phigros 4.0.1（157），应用版本号 173，arm64-v8a。

本次按项目所有者要求发布到正式发行渠道。173 的电脑端检查已经通过，但尚未进行真机验收；“正式发行”不代表所有手机或所有谱面均已实测。172 预发行版和 167 历史发行版保留。

## 下载与安装

1. 下载本 Release 的全部三个 `Phigros-offline-v173.7z.001/.002/.003` 和 `SHA256SUMS.txt`，放在同一目录，保留完整文件名。
2. 用 7-Zip 打开 `.001` 一次解压，得到 `Phigros-offline-v173.apk`。不需要密码；三个分卷不能直接安装，也不用分别解压。
3. 对照 SHA256SUMS.txt 校验分卷和 APK。Windows 可使用 `Get-FileHash -Algorithm SHA256 -LiteralPath '文件路径'`。
4. 先备份修改版自己的数据，然后覆盖安装。173 与 172 的签名一致，不要为了升级卸载或清除数据。系统如果报告签名冲突，请保留原数据与错误信息。
5. 修改版包名为 `com.PigeonGames.Phigros.offline`，正版为 `com.PigeonGames.Phigros`；各自保存数据。不要把修改版存档覆盖到正版。运行不依赖 root、LSPosed 或另装 Phira。

## 173 新增与修正

- 判定规则支持 Perfect、Miss、Good 随机早晚、Good Early、Good Late 和 Bad；可搭配按键种类、指定编号、范围、列表、随机数量、连续数量或全部音符。规则从上到下优先，Perfect 可保护指定音符。
- 目标分数和目标准确率自动分配的 Good 混合早晚；少量 Good 不保证两侧数量相等。Good 的 Early/Late 权重相同，均为 0.65。
- 保留黄键/红键强制 Good/Bad 的非标准玩法。蓝键和长条提前或延后实际接触；黄键/红键沿用强制判定并传递早晚参数。
- 预估考虑长条结算、不同按键漏判阈值、Good 早晚顺序、真实音符总数及普通/挑战计分。结算后本体浮窗显示实际统计，分数通过实际判定产生，不直接覆盖结果数字。
- 自制章节、Phira 格式本地谱包导入、音符皮肤、独立存档、RKS、本地 Data 和资源单份储存继续保留。自制播放器在进入谱面时读取配置，尚无播放器内实时控制浮窗。

在选曲页按音量上键打开面板，保存后下一局生效。冷启动自动游玩默认关闭；自动会话产生的本体成绩在下一次冷启动恢复，配置保留。普通自制谱本地记录与本体独立，自动自制谱记录不保存、不上传。

## 验证与限制

已通过 10 项 C/JVM 回归、8 项自制章节判定测试、浏览器菜单交互、ARM64 构建、签名一致性、16KB 对齐、资源 CRC 与断网权限检查。构建和浏览器测试不能替代真机游玩验证。本次没有安装或操作手机。

普通模式全部 Good 且全连应为 685000 分，挑战模式全部 Good 应为 650000 分。用户报告的某局 658000 分尚缺实际判定统计，具体原因未复现确认。预测仍受帧内顺序、特殊谱面与实际执行影响；离散判定不能保证任意目标都精确命中。

自制谱支持带 info.yml/info.txt 的 .pez/ZIP，识别 PGR/RPE JSON、PEC、PBC；不支持视频后端和 info.csv。皮肤支持标准八图及长条图集，不支持任意 Phira 扩展资源包。游戏无 INTERNET/网络状态权限、无登录途径；可拦截的 HTTP 请求本地返回 403，系统拒绝的原始套接字并无 HTTP 状态码。
