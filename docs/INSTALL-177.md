# 177 安装说明

177是Phigros 4.0.1（157）arm64-v8a的本地实验预发行候选。它不能登录，不声明网络权限，不提供排行榜或云存档操作。

## 下载

下载以下全部文件，放在同一文件夹并保持文件名：

- `Phigros-offline-v177.z01`
- `Phigros-offline-v177.z02`
- `Phigros-offline-v177.zip`
- `SHA256SUMS.txt`

从最后的 `.zip` 选择解压，不要单独解压 `.z01`，不要改名成 `.zip.001`。这是标准ZIP分卷，需要支持ZIP分卷的解压器，无密码。解出APK后再核对APK的SHA-256。

## 安装

APK包名是 `com.PigeonGames.Phigros.offline`，可与正版 `com.PigeonGames.Phigros` 共存。升级前先保留修改版自己的数据和自制谱；不要卸载，也不要清除正版或修改版数据。它不会覆盖正版存档。

首次使用需要授予悬浮窗权限。音量上键打开面板，下键关闭；冷启动自动游玩默认关闭。

## 177验收重点

1. 冷启动进入主页，打开第九章异象、收藏页和穹顶孤舟相关页面。
2. 关闭自动游玩时手动游玩，确认游戏未加载本局原生控制。
3. 开启自动游玩，分别测试触摸屏蔽开启和关闭。
4. 设置随机K规则、S/FC/AT保护和额外保护分数，完成整局并查看结算与历史。
5. 完全退出并冷启动，确认配置保留、自动游玩回到关闭、自动会话成绩按既有规则恢复。
6. 确认原版仍可启动，且修改版数据目录没有写到正版目录。

主机测试通过不等同于上述真机验收通过。Phigros 4.0.1.2没有对应APK和ELF，本版不能宣称兼容。
