# 安装 Phigros 离线修改版

## 下载

从 [v186 预发行](https://github.com/yskzctx/phigros-offline-lab/releases/tag/v186-pre.1) 下载四个分卷：

```
Phigros-offline-v186.z01
Phigros-offline-v186.z02
Phigros-offline-v186.z03
Phigros-offline-v186.zip
```

**四个文件放在同一个文件夹**，对最后的 `.zip` 解压，没有密码。分卷是标准 ZIP 格式，解压工具会依次读取 `.z01`–`.z03`。

## 安装

1. **先卸载旧版**。签名是 `CN=Phigros Offline v181`，与早期版本不同，覆盖安装会失败。
   - 卸载会清空修改版数据。**卸载前先备份** `files/` 和 `shared_prefs/`，或用面板的「导出存档」。
2. 安装解压出的 `Phigros-offline-v186.apk`。
3. 首次启动会检查并准备初始 Data（至少 10000 MB）。

## 首次使用

进入游戏后从浮窗打开控制面板。建议顺序：

1. **初始 Data** — 自动准备
2. **恢复历史成绩与全解锁** → 「全解锁 ＋ 全部 AP」— 解锁全部曲目、收藏品、曲绘、头像
3. **这局怎么打** — 选判定保护模式，开「自动游玩」开关
4. **结算页强制显示** — 按需开启
5. 改完设置后**完全退出并重启**才生效（游戏把配置缓存在内存）

## 常见问题

**启动即闪退**
本版三个原生库齐全（`phigros_offline` / `phigros_privacy` / `phigros_skins`），构建时会校验。若仍闪退，请回报机型与 Android 版本。

**判定保护不生效**
需要开启「自动游玩」开关 —— 这是该功能的语义（在自动游玩引擎上接管判定），不是 bug。

**改了设置没效果**
完全退出游戏进程再打开。

**曲库缺新歌**
曲库表是 4.1.0 的 1072 条 / 329 首。但离线版本体仍是 4.0.1(157) 的游戏数据，所以超出版本范围的谱面无法游玩。要在 4.1.0 上玩，用 Phigros 模块挂原版。

## 关于存档导入

「导入 / 导出存档」支持游戏原始 `playerprefs.xml` 或面板导出的 ZIP。导入前会自动备份，可在同一面板一键回退。导入后必须完全退出重启。
