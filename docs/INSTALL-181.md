# v181 安装说明（157 / 4.0.1）

> **本轮没有真机验收。** 全部验证都在主机侧完成（18 项检查：C 回归、Java 编译与逻辑测试、NDK 交叉编译、源码与 profile 一致性、APK 组装与签名校验）。判定保护整局、皮肤、强制结算、成绩同步都需要你自己在手机上确认。

## 这一版换了签名 —— 必须先卸载旧版

旧包（v165 及更早）的签名是 `CN=Phigros Offline Personal`，私钥不在本机，也不在两个仓库的任何历史里。因此 v181 用新签名库签发，**无法覆盖安装旧版**。

新签名：

```
CN=Phigros Offline v181, O=Local Offline Modification, C=ZZ
```

### 卸载前先备份（重要）

修改版的数据在独立目录里，卸载会清空。先导出：

```sh
adb shell run-as com.PigeonGames.Phigros.offline tar -c files shared_prefs 2>/dev/null > offline-data.tar
```

没有 root 也能用 `run-as`，因为这是可调试签名的应用。或者用手机上的文件管理器把
`/data/data/com.PigeonGames.Phigros.offline/` 下的 `files` 与 `shared_prefs` 复制出来。

**卸载会清空修改版数据，但不影响原版 Phigros**（包名不同，互不干扰）。

### 安装

```sh
adb uninstall com.PigeonGames.Phigros.offline
adb install Phigros-offline-v181.apk
```

安装后首次启动会重新准备资源，需要一些时间与至少 3.4GB 可用空间。

### 恢复数据

安装并启动过一次之后，把备份的 `files` 与 `shared_prefs` 放回同一路径，再强停重开。
历史成绩、全解锁状态与自制谱都在里面。

## 这一版修了什么

| 问题 | 原因 | 现在 |
|---|---|---|
| 判定保护完全没用 | Java 解析层与原生校验层都只接受 `mode 0..2`，面板里已经写好的保护逻辑永远走不到 | `mode=3` 是正式模式，保护 AP / 保护 FC / 保护分数三档可用 |
| 导入皮肤后音符大小忽大忽小 | 缩放只锁宽度，高度跟着皮肤 PNG 的长宽比漂移 | 两轴同时锁定，同包各槽位缩放一致 |
| 成绩无法同步 | 成绩写入在自动会话里被吞掉；HTTP 被强制改成 403 | 写入始终执行；HTTP 拦截移除 |
| （模块）云存档观察器是死代码 | `cloud-guard.c` 提交了但从未被编译进模块 | 已内联进 `.so`，面板能显示宿主是否真的调用了同步接口 |

新增**结算页强制显示**独立开关（与自动游玩、判定保护互不影响）：开启后结算页显示你填的分数、准确率、Perfect / Good / Bad / Miss、最大连击，包括真实一局不可能出现的组合，并写入本地历史；RKS 由成绩派生，因此会跟着变。

## 4.1.0 不包含

4.1.0（161）底包已取得并分析，`tools/recover_profile.py` 恢复了 **7/13** 个 hook：4 个皮肤 `NoteMove` 由两项证据共同确认，6 个判定 hook 因序言过短且调用者众多无法判定。把版本号改成 4.1.0 会得到「能装但判定行为错误」的包，所以本版仍是 4.0.1（157）。


## 边界

- 不声明网络权限、不能登录、不提供排行榜或云存档。
- 自动游玩与判定干预产生的数据是模拟数据，不是真实手动成绩。
- 原生章节的扩展特效、音效、判定线颜色仍未完成；皮肤能改的是游戏自己用 PlayerPrefs 保存的那几项（击中特效开关、特效音量、音效音量、音符缩放、判定线颜色）。
