# 172 预发行版：自制章节与音符皮肤

发布日期：2026-10-15。游戏内容基于 Phigros 4.0.1（157），应用版本号 172，仅 arm64-v8a。

**这是待真机验证的预发行版。** 主机、JVM、ARM64 构建和打包检查已通过；本次没有可用手机，不保证实际启动、声音、触摸、章节返回及特殊页面正常。167 继续作为正式版。

## 下载、校验与安装

1. 下载同一 Release 的全部三个 `Phigros-offline-172-pre.1.7z.001/.002/.003` 和 `SHA256SUMS.txt`，放进同一文件夹，保留完整文件名。
2. 用 7-Zip 打开 `.001`，解压后进入 `outputs/controls172` 文件夹，找到 `Phigros-4.0.1-157-offline-arm64-controls-v172-COMBINED-CANDIDATE.apk`。分卷不是 APK，不能直接安装，也不用逐卷解压。无解压密码。
3. 对照 `SHA256SUMS.txt` 核对分卷和解压出的 APK。Windows 可用 PowerShell：`Get-FileHash -Algorithm SHA256 -LiteralPath '文件路径'`。
4. 安装前备份自己的修改版数据。与本项目原签名一致的旧修改版可尝试覆盖升级；不要为升级卸载或清除应用数据。若系统提示签名冲突，先停止，不要删除已有数据。
5. 修改版包名 `com.PigeonGames.Phigros.offline`，正版为 `com.PigeonGames.Phigros`。二者数据目录独立，勿将修改版数据覆盖到正版。运行不需要 root、LSPosed 或 Phira 应用。

## 从哪里打开新功能

启动后按音量上键打开控制浮窗。进入“存档”页，可以看到“我的自制章节”和“音符皮肤”入口。需要悬浮窗授权时按系统提示授予。

先在“游玩”和“判定规则”页保存配置，再打开自制章节开始一局。自制播放器在开始时读取自动游玩状态、目标分数/准确率和规则；尚未提供播放器内部实时修改配置的浮窗。

### 自制谱

- 导入带 `info.yml` 或 `info.txt`、谱面、音乐和插画的 `.pez` / ZIP 本地自制包。单层包装文件夹可以导入。当前不支持 `info.csv` 元信息。
- 后端识别 PGR/RPE JSON、PEC、PBC；导入成功只代表包结构检查通过，实际谱面解码在打开播放器时进行。
- 不接受在线谱面身份字段或解锁视频条件，不会删除身份字段来绕过验证。
- 手动自制谱记录独立保存在该谱包的 `local-record.json`；自动游玩没有成绩保存或上传回调，不参与官方曲目记录及历史 RKS。
- 目标分数/准确率通过实际 Miss/Good 等判定计划接近目标，规则优先；受音符数量、长条结算顺序影响，不保证任意数值精确命中。控制模式限 20000 个真实音符，超过时明确拒绝。

### 音符皮肤

- ZIP 内需有 `info.yml`，以及 `click/drag/flick/hold.png` 和对应 `_mh.png` 共八张图片；支持 `holdAtlas` / `holdAtlasMH` 长条图集参数。
- 导入后选择“使用此皮肤”，完全退出并重启应用。官方曲目和自制章节共用所选皮肤；自制播放器补用默认判定特效和音效。
- 暂不支持 `holdRepeat`、`holdCompact`、`holdKeepHead` 扩展和自定义判定特效/音效，不能将任意完整 Phira 资源包都视作兼容。

## 建议先用附带原创素材检查

附带的 `demo-chart-four-notes.pez` 和 `demo-note-skin.zip` 使用本项目生成的测试音符图、插画与短音频，不是其他作者的谱包。导入它们后分别检查手动/自动游玩、长条头尾、音乐、返回游戏、重启后记录与皮肤选择。还需检查原有章节、异象和收藏页面。

修改版没有 INTERNET 或网络状态权限，登录组件已移除；可拦截的 HTTP/HTTPS 在本地拒绝并返回 403。原始套接字/DNS 被系统拒绝时没有 HTTP 状态码。
